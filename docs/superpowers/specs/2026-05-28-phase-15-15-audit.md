# Phase 15 #15 — Consistency Audit

> Read-only audit produced as PR A of sub-project #15.
> Findings drive PR B (cross-cutting) and PRs G1–G13 (per-game).
> Format: `- [P1|P2|P3] <surface> · <finding> · <fix>`

## Conventions

- **P1:** breaks design language or usability (wrong color token, missing focus ring on interactive, empty state shows nothing).
- **P2:** noticeable polish gap (spacing drift, capitalisation inconsistency, missing aria-label on icon-only button).
- **P3:** nice-to-have (tighter animation curve, slightly better copy).
